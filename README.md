# DWEC - Desarrollo Web en Entorno Cliente

Repositorio de prácticas, ejercicios y proyectos de la asignatura **Desarrollo Web en Entorno Cliente (DWEC)** del ciclo formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

## ⚙️ Configuración y Ejecución

1. Clona el repositorio:
   ```bash
   git clone git@github.com:GlebNesterov/DWEC.git
   ```

2. Entra en la carpeta del tema o proyecto correspondiente e instala dependencias (si aplica):
   ```bash
   cd nombre-carpeta
   npm install
   ```

3. Inicia el servidor de desarrollo local:
   ```bash
   npm run dev
   ```
